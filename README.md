# My_portfolio

Site pour montrer mes différents projets réalisés.

Application React (Vite + TypeScript + Tailwind CSS) — voir [frontend/](frontend/).

## Développement local

```bash
cd frontend
npm install
npm run dev
```

## Déploiement

Déployé sur [Vercel](https://vercel.com). Lors de l'import du projet, définir le **Root Directory** sur `frontend` (build command et output directory sont auto-détectés pour Vite).
